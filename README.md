# 📊 Customer Churn Prediction using Machine Learning

## 🔍 Project Overview
This project focuses on predicting customer churn in a subscription-based business using machine learning techniques. It also aims to identify key factors influencing customer churn to support data-driven business decisions.

---

## 🎯 Problem Statement
- **Objective:** Identify customers at high risk of churning and uncover key drivers behind churn behavior  
- **Type:** Binary Classification  
- **Target Variable:** Churn (1 = Yes, 0 = No)

---

## 💼 Business Goal
- Detect high-risk customers at an early stage  
- Enable businesses to design targeted retention strategies  
- Reduce customer attrition and revenue loss  

---

## 🛠️ Approach
- Performed **Exploratory Data Analysis (EDA)** to understand customer behavior  
- Identified **class imbalance** in churn distribution  
- Applied **data preprocessing** (encoding, cleaning, etc.)  
- Built and evaluated models:
  - Logistic Regression  
  - Decision Tree  
- Used evaluation metrics like **Accuracy, Precision, Recall, and F1-score**

---

## 📈 Key Insights
- Customers with **shorter tenure** are more likely to churn  
- Higher **monthly charges** are associated with increased churn risk  
- Certain service features significantly influence customer retention  

---

## 📊 Results
- Logistic Regression provided a balanced performance across precision and recall  
- Model can help businesses proactively identify at-risk customers  

---

## 🚀 Future Scope
- Improve performance using advanced models and hyperparameter tuning  
- Handle class imbalance using techniques like SMOTE  
- Deploy the model using Streamlit for real-time predictions
